How Golf STRIPS Planning Works

1. Initial State

Golf Tee starting state: At(GolfBall, (1,1)), fairway cells, and tree/water hazards.

2. Goal State

Target Hole condition to satisfy: At(GolfBall, (4,5)).

3. Preconditions

Requirements before hitting ball (ball location, target fairway cell exists and is clear of hazards).

4. Golf Stroke Operators

Stroke actions: STROKE-NORTH, STROKE-SOUTH, STROKE-WEST, STROKE-EAST (10m per stroke).

5. Effects (Add & Delete)

State transition: Delete List removes previous ball location, Add List asserts new fairway location.

6. Goal-Stack Mechanism

Pushes intermediate fairway sub-goals onto stack to decompose course path and navigate into the target hole.
